Tabela: comentarios

Campos:
  • id                INT UNSIGNED PRIMARY KEY AUTO_INCREMENT
  • produto_id       INT UNSIGNED (FK → produtos.id)
  • nome              VARCHAR(120) - Nome do visitante
  • email             VARCHAR(180) - Email validado
  • comentario        TEXT - Conteúdo do comentário
  • avaliacao         INT - 0-5 estrelas
  • status            ENUM('Pendente','Aprovado','Rejeitado')
  • criado_em         TIMESTAMP - Data de criação

Relacionamento:
  • Foreign Key com DELETE CASCADE
  • Foreign Key com UPDATE CASCADE
  • Integridade referencial garantida
