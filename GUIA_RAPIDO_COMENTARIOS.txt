# GUIA RÁPIDO - SISTEMA DE COMENTÁRIOS

## 🚀 Começar Rapidamente

### Passo 1: Atualizar Banco de Dados
1. Abra `database.sql`
2. Execute o script no seu MySQL/PHPMyAdmin
3. A tabela `comentarios` será criada automaticamente

### Passo 2: Acessar o Sistema

#### Para Deixar Comentário (Visitante)
```
http://seu-site.com/form_comentario.php?produto_id=1
```

#### Para Gerenciar Comentários (Admin)
1. Faça login no painel administrativo
2. Acesse: http://seu-site.com/comentarios.php
3. Ou clique em "Comentários" na página de Produtos

### Passo 3: Moderar Comentários
- **Aprovar**: Clique em "Aprovar" para comentário ficar visível
- **Rejeitar**: Clique em "Rejeitar" para esconder comentário
- **Excluir**: Clique em "Excluir" para remover comentário

## 🎨 Interface

### Visitante vê:
- Foto do produto
- Nome do produto
- Formulário para comentar (Nome, Email, Avaliação, Texto)
- Seletor de estrelas (1-5 ⭐)
- Comentários aprovados anteriores

### Admin vê:
- Lista de todos os comentários
- Filtros por Produto e Status
- Ações: Aprovar, Rejeitar, Excluir
- Contagem de comentários pendentes

## ✨ Funcionalidades

### Validações
- ✅ Nome obrigatório
- ✅ E-mail obrigatório e validado
- ✅ Comentário obrigatório
- ✅ Avaliação de 1-5 estrelas (opcional)
- ✅ Segurança contra SQL Injection e XSS

### Status dos Comentários
1. **Pendente** - Aguardando aprovação (amarelo)
2. **Aprovado** - Visível para todos (verde)
3. **Rejeitado** - Oculto mas ainda no banco (vermelho)

### Filtros
- Filtrar por Produto
- Filtrar por Status
- Limpar filtros

## 🔐 Segurança

✅ Comentários com "Pendente" não aparecem para visitantes
✅ Apenas admin autenticado pode moderar
✅ Proteção contra XSS com htmlspecialchars()
✅ Proteção contra SQL Injection com Prepared Statements
✅ Confirmação de exclusão antes de remover

## 🎯 Casos de Uso

### Cenário 1: Visitante deixa comentário
```
1. Vai em: form_comentario.php?produto_id=1
2. Preenche: Nome, Email, Avaliação, Comentário
3. Clica: "Enviar Comentário"
4. Vê: Mensagem "Seu comentário está aguardando aprovação!"
```

### Cenário 2: Admin aprova comentário
```
1. Vai em: comentarios.php
2. Vê: Lista com novo comentário (status Pendente)
3. Clica: "Aprovar"
4. Resultado: Comentário agora aparece no formulário do produto
```

### Cenário 3: Admin rejeita comentário
```
1. Vai em: comentarios.php
2. Filtro: "Status" = "Pendente"
3. Clica: "Rejeitar"
4. Resultado: Comentário fica oculto (status Rejeitado)
```

## 🐛 Troubleshooting

### Tabela de comentários não encontrada
**Solução**: Execute o comando SQL em `database.sql`

### Comentários não aparecem
**Solução**: Verifique se status é "Aprovado" em `comentarios.php`

### Erro ao salvar comentário
**Solução**: Verifique se:
- Produto existe (ID válido)
- E-mail é válido
- Nenhum campo está vazio

### Ligação "Comentários" não funciona
**Solução**: Verifique se o arquivo `comentarios.php` está no mesmo diretório que `produtos.php`
