---|---|---

## 📋 FLUXO RÁPIDO

### 1️⃣ Visitante Deixa Comentário
```
form_comentario.php?produto_id=1
        ↓
    (Preenche formulário)
        ↓
  salvar_comentario.php
        ↓
  Status: PENDENTE ⏳
```

### 2️⃣ Admin Modera
```
comentarios.php
        ↓
    (Visualiza)
        ↓
  Aprova / Rejeita / Deleta
        ↓
  Status: APROVADO ✅ ou REJEITADO ❌
```

### 3️⃣ Comentário Aprovado Aparece
```
Visitante vê em:
form_comentario.php?produto_id=1
```

## 📞 DÚVIDAS FREQUENTES

### P: Qual arquivo editar?
A: Depende do seu objetivo:
- Mudar cor? → `assets/css/style.css`
- Adicionar funcionalidade? → `comentarios.php` ou `form_comentario.php`
- Mudar texto? → Procure em qualquer arquivo PHP

### P: Posso personalizar?
A: Sim! Todos os arquivos foram criados para serem editáveis.

### P: Como desinstalar?
A: Delete os 6 arquivos PHP e revert `produtos.php` do backup.

### P: É seguro usar em produção?
A: Sim! Sistema implementado com boas práticas de segurança.
