# 🚀 INSTRUÇÕES DE INSTALAÇÃO - SISTEMA DE COMENTÁRIOS

## ✅ Pré-requisitos

- [x] PHP 7.4 ou superior
- [x] MySQL 5.7 ou superior
- [x] XAMPP/WAMP/LAMP instalado e funcionando
- [x] Sistema existente com autenticação (`auth.php`, `conexao.php`)

## 📥 Instalação Passo a Passo

### PASSO 1: Atualizar Banco de Dados

#### Opção A: Usando PHPMyAdmin

1. Abra PHPMyAdmin em `http://localhost/phpmyadmin`
2. Selecione o banco `empresa_acessorios`
3. Clique em "SQL"
4. Copie e cole o seguinte código:

```sql
CREATE TABLE IF NOT EXISTS comentarios (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    produto_id INT UNSIGNED NOT NULL,
    nome VARCHAR(120) NOT NULL,
    email VARCHAR(180) NOT NULL,
    comentario TEXT NOT NULL,
    avaliacao INT DEFAULT 0,
    status ENUM('Pendente','Aprovado','Rejeitado') NOT NULL DEFAULT 'Pendente',
    criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_comentarios_produtos
        FOREIGN KEY (produto_id) REFERENCES produtos(id)
        ON DELETE CASCADE
        ON UPDATE CASCADE
) ENGINE=InnoDB;
```

5. Clique em "Executar"

#### Opção B: Usando Arquivo SQL

1. Abra o arquivo `database.sql`
2. Execute no seu MySQL client
3. A tabela será criada automaticamente

## 🐛 Troubleshooting

### Erro: "Tabela comentarios não existe"

**Solução:**
1. Execute novamente o SQL de criação
2. Verifique se o banco está correto
3. Confirme que as permissões estão ok

### Erro: "Erro ao salvar comentário"

**Solução:**
1. Verifique logs do PHP
2. Confirme conexão com banco
3. Teste if produto_id é válido

### Comentários não aparecem

**Solução:**
1. Verifique se status é "Aprovado"
2. Confirme que produto existe
3. Limpe cache do navegador (Ctrl+Shift+Del)

### Página em branco

**Solução:**
1. Ative modo debug: adicione `error_reporting(E_ALL);` no topo do PHP
2. Verifique logs de erro do servidor
3. Confirme sintaxe PHP

### Arquivo 404 Not Found

**Solução:**
1. Verifique nome exato do arquivo
2. Confirme localização correta
3. Verifique permissões de arquivo (644)

### Erro de permissão de banco

**Solução:**
1. Verifique credenciais em `conexao.php`
2. Confirme usuário MySQL tem privilégios
3. Execute: `GRANT ALL ON empresa_acessorios.* TO 'root'@'localhost';`
