## 🚀 Como Usar

### 1. Atualizar Banco de Dados
Execute o arquivo `database.sql` para criar a tabela de comentários.

### 2. Acessar Comentários como Visitante
```
www.seu-site.com/form_comentario.php?produto_id=1
```
Substituir `1` pelo ID do produto desejado.

### 3. Gerenciar Comentários (Admin)
```
www.seu-site.com/comentarios.php
```
Requer autenticação de usuário.

## 📊 Fluxo de Comentários

```
Visitante deixa comentário 
    ↓ (Status: Pendente)
    ↓
Admin aprova no painel
    ↓ (Status: Aprovado)
    ↓
Comentário aparece para todos na página de produto
```

- E-mail: obrigatório, validado como email

- Produto: verificado se existe
