## 🗄️ Banco de Dados

Tabela criada: `comentarios`

```sql
CREATE TABLE comentarios (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    produto_id INT UNSIGNED NOT NULL,
    nome VARCHAR(120) NOT NULL,
    email VARCHAR(180) NOT NULL,
    comentario TEXT NOT NULL,
    avaliacao INT DEFAULT 0,
    status ENUM('Pendente','Aprovado','Rejeitado') DEFAULT 'Pendente',
    criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (produto_id) REFERENCES produtos(id)
    ON DELETE CASCADE
)
```

## 🚀 Como Usar

### 1️⃣ Executar Instalação

```bash
1. Abra PHPMyAdmin
2. Execute o SQL em database.sql
3. Confirme se tabela 'comentarios' foi criada
```

### 2️⃣ Visitante Deixa Comentário

```
Abra: http://seu-site.com/form_comentario.php?produto_id=1

Preencha:
- Nome
- Email
- Avaliação (estrelas)
- Comentário

Clique: "Enviar Comentário"
```

### 3️⃣ Admin Modera

```
Acesse: http://seu-site.com/comentarios.php

Ações disponíveis:
- Filtrar por Produto
- Filtrar por Status
- Aprovar comentário
- Rejeitar comentário
- Excluir comentário
```

### 4️⃣ Comentário Aprovado Aparece

Quando aprovado, o comentário fica visível para todos na página:
```
http://seu-site.com/form_comentario.php?produto_id=1
```
