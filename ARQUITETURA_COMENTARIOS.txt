# ARQUITETURA DO SISTEMA DE COMENTÁRIOS

## 📊 Fluxo de Dados

```
┌─────────────────────────────────────────────────────────────────────┐
│                         SISTEMA DE COMENTÁRIOS                       │
└─────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│                              VISITANTE (Público)                         │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  form_comentario.php?produto_id=1                                       │
│  ├─ Exibe dados do produto                                              │
│  ├─ Formulário: Nome, Email, Avaliação, Comentário                      │
│  ├─ Validações interativas (JavaScript)                                 │
│  ├─ Envia para: salvar_comentario.php (POST)                           │
│  └─ Lista comentários aprovados anteriores                              │
│                                                                          │
│  Resultado: Comentário com status "Pendente"                           │
│  Mensagem: "Aguardando aprovação"                                       │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
                        ┌──────────────────────┐
                        │  Banco de Dados:     │
                        │  Tabela comentarios  │
                        │                      │
                        │  - id                │
                        │  - produto_id       │
                        │  - nome              │
                        │  - email             │
                        │  - comentario        │
                        │  - avaliacao         │
                        │  - status (Pendente) │
                        │  - criado_em         │
                        └──────────────────────┘
                                     │
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                        ADMINISTRADOR (Autenticado)                       │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  comentarios.php                                                         │
│  ├─ Requer autenticação (require_once 'auth.php')                       │
│  ├─ Lista todos os comentários                                          │
│  ├─ Filtros:                                                            │
│  │  ├─ Por Produto                                                      │
│  │  └─ Por Status (Pendente, Aprovado, Rejeitado)                      │
│  │                                                                       │
│  ├─ Ações:                                                              │
│  │  ├─ Aprovar      → aprovar_comentario.php?id=X                      │
│  │  │                 (Status: Pendente → Aprovado)                     │
│  │  ├─ Rejeitar     → rejeitar_comentario.php?id=X                     │
│  │  │                 (Status: Pendente → Rejeitado)                    │
│  │  └─ Excluir      → excluir_comentario.php?id=X (com confirmação)    │
│  │                    (Deleta do banco de dados)                        │
│  │                                                                       │
│  └─ Contagem de comentários pendentes                                   │
│                                                                          │
│  Acesso também via:                                                      │
│  └─ produtos.php (botão "Comentários" + coluna na tabela)              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
                        ┌──────────────────────┐
                        │ Status Atualizado:   │
                        │ "Aprovado" ou        │
                        │ "Rejeitado"          │
                        └──────────────────────┘
                                     │
                                     ▼
                        ┌──────────────────────┐
                        │  Comentário Visível  │
                        │  para Visitantes em  │
                        │  form_comentario.php │
                        │  (somente Aprovados) │
                        └──────────────────────┘
```

## 🔐 Fluxo de Segurança

```
ENTRADA
   │
   ▼
┌──────────────────────────────────────┐
│  Validação Client-Side (JavaScript)  │
│  ├─ Nome obrigatório?                │
│  ├─ Email válido?                    │
│  ├─ Comentário preenchido?           │
│  └─ Avaliação entre 0-5?             │
└──────────────────┬───────────────────┘
                   │
                   ▼
┌──────────────────────────────────────┐
│   Validação Server-Side (PHP)        │
│  ├─ Campo vazio?                     │
│  ├─ Email filter_var?                │
│  ├─ Comprimento válido?              │
│  ├─ Produto existe?                  │
│  └─ Avaliação 0-5?                   │
└──────────────────┬───────────────────┘
                   │
                   ▼
┌──────────────────────────────────────┐
│   SQL Injection Prevention            │
│  ├─ Prepared Statements (PDO)        │
│  ├─ Placeholders (?)                 │
│  └─ Nenhuma concatenação             │
└──────────────────┬───────────────────┘
                   │
                   ▼
┌──────────────────────────────────────┐
│   XSS Prevention                     │
│  ├─ htmlspecialchars() em outputs    │
│  ├─ nl2br() para quebras de linha    │
│  └─ Nenhuma tag HTML renderizada     │
└──────────────────┬───────────────────┘
                   │
                   ▼
┌──────────────────────────────────────┐
│   Autenticação (Admin)               │
│  ├─ Requer session autenticada       │
│  ├─ require_once 'auth.php'          │
│  └─ Redireção se não autenticado     │
└──────────────────┬───────────────────┘
                   │
                   ▼
           ✅ SEGURO - Salvo
```

## 🔗 Fluxo de URLs e Links

```
VISITANTE:
form_comentario.php?produto_id=1
    ├─ (GET) Exibe formulário + comentários aprovados
    └─ (POST para salvar_comentario.php)
           ├─ Validações
           ├─ Salva no DB (status Pendente)
           └─ Redireciona com mensagem

ADMINISTRADOR:
comentarios.php
    ├─ Listar todos os comentários
    ├─ Filtros: produto, status
    │
    ├─ Link: aprovar_comentario.php?id=X
    │   └─ UPDATE status = 'Aprovado'
    │
    ├─ Link: rejeitar_comentario.php?id=X
    │   └─ UPDATE status = 'Rejeitado'
    │
    └─ Link: excluir_comentario.php?id=X
        └─ DELETE comentário

INTEGRAÇÃO:
produtos.php
    ├─ Exibe coluna "Comentários"
    │   ├─ Total de comentários
    │   └─ Badge com pendentes
    │
    ├─ Link: "Comentários" (no header)
    │   └─ comentarios.php
    │
    └─ Ação: "Comentários" (por produto)
        └─ form_comentario.php?produto_id=X
```

## 📊 Tabela de Dados

```sql
comentarios
├── id (INT UNSIGNED AUTO_INCREMENT PRIMARY KEY)
├── produto_id (INT UNSIGNED FK → produtos.id)
├── nome (VARCHAR 120)
├── email (VARCHAR 180)
├── comentario (TEXT)
├── avaliacao (INT 0-5)
├── status (ENUM: 'Pendente', 'Aprovado', 'Rejeitado')
└── criado_em (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
```
